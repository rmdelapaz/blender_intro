## SVG Diagram Recommendations

### **High Priority for SVG:**

1. **Mix Shader vs Mix Color Diagram (#14)**
   - **Rationale:** Pure diagrammatic content with text, arrows, and decision logic. No photorealistic rendering needed. SVG ensures perfect clarity at any zoom level and tiny file size compared to raster formats.

2. **Layered Material Structure Diagram (#19)**
   - **Rationale:** Hierarchical flowchart with boxes and arrows showing material assembly. Vector format perfect for educational diagrams. Scales perfectly for web, presentations, or print without quality loss.

3. **Professional Material Workflow Flowchart (#43)**
   - **Rationale:** Complex decision tree with multiple paths and decision points. SVG allows perfect scaling and easy editing if workflow needs future updates. Text remains crisp at all sizes.

4. **Multi-Layer Material Decision Tree (#50)**
   - **Rationale:** Logic flow diagram with decision diamonds and outcome boxes. SVG maintains perfect clarity of text and connection lines at any size, essential for reference material.

5. **Triplanar Mapping Concept (#11)**
   - **Rationale:** Geometric technical diagram with projection lines, planes, and annotations. Vector graphics ideal for this engineering-style technical illustration. Projection rays and text annotations remain sharp.

6. **Scale Hierarchy Concept (#44)**
   - **Rationale:** Simple educational diagram with labeled sections showing scale relationships. SVG keeps file size minimal while maintaining perfect quality for all viewing contexts.

7. **Material Artist's Toolkit Infographic (#45)**
   - **Rationale:** Grid of simple icons with text labels and descriptions. SVG allows infinite scaling for different uses (web thumbnails to printed posters) while keeping file size tiny.

8. **Color Palette for Materials (#49)**
   - **Rationale:** Simple geometric shapes (color swatches) with text and hex codes. SVG perfect for maintaining exact color values and crisp text. Easy to update if palette changes.

### **Medium Priority for SVG:**

9. **PBR Parameter Quick Reference (#47)**
   - **Rationale:** Data table with text and numerical values. SVG ensures text remains perfectly readable at all sizes and makes table data accessible to screen readers.

10. **Mask Combination Techniques (#18)**
    - **Rationale:** Diagrams showing mathematical operations with grayscale patterns. Could be SVG with embedded raster graphics for the mask textures themselves, or pure raster if gradients are complex.

### **Why SVG for These Specific Images:**

**Technical Benefits:**
- **Infinite Scalability:** No quality loss from 16px icon to billboard size
- **Tiny File Sizes:** Often 10-100x smaller than equivalent raster images
- **Text Accessibility:** Text remains selectable and screen-reader friendly
- **Easy Updates:** Edit in code or vector editors without regeneration
- **Perfect for Web:** Responsive design, crisp on retina displays
- **Print Ready:** Automatically resolution-independent

**Content Characteristics Making SVG Ideal:**
- Composed primarily of geometric shapes (boxes, circles, arrows)
- Contains substantial text labels and annotations
- Requires crisp lines and edges
- Benefits from zoom without pixelation
- May need future editing or translation

### **Not Recommended for SVG:**

- Photorealistic renders (#20-#24, #30, #35-#36, #41)
- Complex node editor screenshots (#16, #26, #31, #37, #42, #48)
- Textured surfaces with noise and gradients (#2-#8, #29, #38-#39)
- UI screenshots requiring authentic appearance
- Materials with complex shading and lighting

**Rationale:** These require raster graphics (PNG) to accurately represent:
- Photographic quality and lighting
- Procedural texture details
- Authentic software interface appearance
- Gradient complexity and noise patterns
- 3D render quality with reflections

## Accessibility Considerations

### Color Blindness
- Don't rely solely on color for information
- Use texture, pattern, and labels
- Test with color blindness simulators
- Minimum contrast: 4.5:1 (WCAG AA)

### Alt Text Requirements
All images must include descriptive alt text covering:
- What is shown
- Key visual elements
- Important findings
- Context and use case

### High Contrast
- Text on images: 7:1 minimum (WCAG AAA)
- UI elements: 3:1 with background
- Diagrams distinguishable in grayscale

### Text Legibility
- Minimum 12pt font (16px)
- Line weight: 2px minimum
- Icon size: 24x24px minimum
- Line height: 1.5x
