## SVG vs PNG Decision Tree

**Use SVG for:**
- Tree diagrams and flowcharts
- Text-heavy infographics
- Tables and reference charts
- Icon-based designs
- Anything needing scalability

**Use PNG for:**
- Blender interface screenshots
- Viewport renders
- Annotated screenshots
- Photo-style comparisons
- Complex UI captures

## Annotation Standards

### Callout Box Template
```
- Rounded corners: 8px radius
- Background: Semi-transparent (#FDD835 at 90% opacity)
- Border: 2px solid darker shade
- Drop shadow: 4px offset, 8px blur, 25% opacity
- Text: White or dark grey depending on background
- Padding: 12px all sides
```

### Arrow/Leader Line Template
```
- Color: Bright cyan (#00E5FF) for visibility
- Width: 3px
- Style: Curved Bezier for elegance
- Arrow head: Filled triangle, 12px
- Drop shadow: Subtle for depth
```

### Text Annotation Standards
```
- Font: Inter, Roboto, or system sans-serif
- Heading size: 18-24px bold
- Body size: 14-16px regular
- Minimum contrast: 4.5:1 ratio
- Line height: 1.4-1.6 for readability
```

## Troubleshooting Guide

### Issue: Screenshot text is blurry
**Solution:** Capture at 2x resolution, downscale with bicubic algorithm

### Issue: SVG looks different in browser vs editor
**Solution:** Convert all text to paths, embed fonts, test in target browsers

### Issue: File size too large
**Solution:** 
- PNG: Use TinyPNG or pngquant compression
- SVG: Run through SVGO, remove hidden layers
- Consider splitting complex images into parts

### Issue: Colors don't match between images
**Solution:** Create color palette swatch file, use eyedropper tool for consistency

### Issue: Annotations not visible at mobile sizes
**Solution:** Create separate mobile-optimized version or increase text/arrow sizes

### Issue: Blender UI looks different from prompt description
**Solution:** Verify Blender version (4.0+), reset theme to defaults, check workspace layout

## Quick Command Reference

### Blender Screenshot Setup
```
1. F11 → Render Region → Take screenshot
2. Or: Window → Save Screenshot
3. Viewport shading: Z → Material Preview
4. Hide UI: Ctrl+Space (toggle maximize)
5. Frame all: Home key
```

### Image Optimization
```
PNG: pngquant --quality=65-80 input.png
SVG: svgo input.svg -o output.svg
Batch PNG: for i in *.png; do pngquant $i; done
```
