## SVG Diagram Recommendations

List of images that work best as SVG:

1. **Coffee Mug Learning Progression Diagram** (#1) - Complex flowchart with multiple connections and text labels, needs to scale perfectly and remain readable at any size. Vector format ideal for arrows, icons, and text.

2. **File Organization Structure** (#26) - Tree diagram with hierarchical connections, folder icons, and text labels. SVG ensures crisp lines and perfect scalability for printing or screen display.

3. **Step-by-Step Checklist Visual** (#29) - Infographic with icons, text, checkboxes, and structured layout. Vector format allows easy editing and perfect rendering at any resolution.

4. **Keyboard Shortcut Reference Card** (#30) - Text-heavy reference with structured layout, table format, and key icons. SVG ensures text remains perfectly sharp and readable.

**Rationale for SVG recommendations:** These images are primarily composed of geometric shapes, text, icons, and line work rather than photorealistic Blender screenshots. SVG format provides:
- Infinite scalability without quality loss
- Crisp text rendering at all sizes
- Easy editing and updating
- Smaller file sizes compared to high-res PNGs
- Perfect for both screen display and printing
- Accessibility benefits (text can be selected, read by screen readers)

## Notes

### Style Consistency Guidelines

**Color Palette:**
- Background: Dark grey (#2b2b2b) - Standard Blender viewport
- Selection highlight: Bright orange (#ff8c00) - Blender's selection color
- Active elements: Bright orange/yellow for cursor, active edges
- Annotation colors: Bright yellow (#FFEB3B) for arrows, boxes, callouts
- Grid: Subtle grey (#404040)
- Text: White (#FFFFFF) with drop shadows or dark backgrounds for visibility
- Success indicators: Green (#4CAF50)
- Warning/problem indicators: Red (#F44336)
- Info/tutorial accents: Purple gradient (#667eea to #764ba2)

**Blender Version:** 4.0 or later (current stable version)

**View Angles:**
- Orthographic for precise technical views (top, front, side)
- Perspective (slight angle) for depth and 3D understanding
- Close-ups at 45-degree angles for detail callouts
- Consistent angles within comparison images

**Selection Highlighting:**
- Active selection: Bright orange outline
- Preview/hover: Yellow outline
- Deselected: Grey/neutral

**Typography:**
- Primary font: Clear sans-serif (Inter, Roboto, or similar)
- Label size: 14-16pt for main labels
- Annotation size: 12-14pt for secondary text
- Headers: 18-20pt bold
- All text with sufficient contrast and readability

**Annotation Style:**
- Arrows: Bold, curved when needed, bright yellow
- Callout boxes: Rounded corners, semi-transparent backgrounds
- Leader lines: Solid, 2px width, yellow
- Number/step indicators: Circular badges with numbers
- Highlight circles: Dotted/dashed yellow outlines

**Wireframe Clarity:**
- Edge visibility mode enabled for technical shots
- Edge thickness: Readable but not overwhelming
- Contrast: Cyan/white edges on dark background

### Accessibility Considerations

**Alt Text Required:** Every image should include descriptive alt text covering:
- What Blender operation is shown
- State of the model (before/after, step X of Y)
- Key visual elements (selection, highlights, geometry)
- Context within the lesson flow

**High Contrast:** 
- Text annotations minimum 4.5:1 contrast ratio
- Yellow annotations on dark grey: 12:1 ratio ✓
- White text on dark backgrounds: 15:1 ratio ✓

**Text Size:**
- Minimum 12pt for body text in images
- Minimum 14pt for labels and callouts
- Minimum 16pt for headers and important indicators

**Diagram Simplicity:**
- One primary concept per image
- Maximum 3-5 labeled elements per screenshot
- Progressive disclosure in multi-panel images
- Clear visual hierarchy

### Technical Specifications

**Screenshot Resolution:**
- Standard: 1920x1080 (Full HD)
- Wide format: 2400x800, 2100x700 for multi-panel
- Tall format: 1200x1600 for vertical infographics
- Detail shots: Minimum 1200x800

**Image Format:**
- PNG for screenshots (lossless, sharp UI elements)
- SVG for diagrams, flowcharts, infographics
- JPG for photorealistic renders (only #23)

**File Size Target:**
- Individual screenshots: <500KB after optimization
- Composites: <800KB
- SVG diagrams: <200KB
- Total lesson image payload: <15MB

**Compression:**
- PNG: TinyPNG or similar optimization
- JPG: 85-90% quality
- SVG: Optimize with SVGO, remove unnecessary metadata

**Responsive Sizing:**
- Desktop: Full resolution
- Tablet: 75% scale
- Mobile: 50% scale with option to view full size
- All text remains readable at mobile sizes
