## Accessibility Considerations

### Visual Clarity
- **High contrast:** White text on dark backgrounds (minimum 7:1 ratio)
- **Large touch targets:** Clickable elements clearly defined
- **Color blindness:** Don't rely solely on color (use labels + color)
- **Font size:** Minimum 12px for body text, 14px preferred

### Alt Text Requirements
Each image must include descriptive alt text:
- **Purpose:** What concept does this image teach?
- **Content:** What's visible in the image?
- **Context:** How does it relate to surrounding text?

Example: "Annotated screenshot of Geometry Nodes editor interface showing header bar with New button, main node workspace with grid background, Group Input and Output nodes connected, and sidebar panel. Labels identify all major interface areas."

### Screen Reader Support
- **SVG diagrams:** Include proper semantic structure (title, desc tags)
- **Complex images:** Provide text alternatives for detailed information
- **Image captions:** Descriptive, not redundant with alt text
