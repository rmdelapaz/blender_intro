- **Selection Highlighting:** Orange outline (#ff8c00) for selected objects
- **Typography:** 
  - Sans-serif fonts (Arial, Helvetica, or Roboto)
  - Labels: 14-18pt
  - Annotations: 12-14pt
  - Headers: 24-36pt bold
- **Annotation Style:** 
  - Orange arrows (#ff8c00) with white labels
  - Rounded rectangle callout boxes
  - Leader lines at 45° angles when possible

### Accessibility Considerations
- All comparison images should have clear visual differentiation beyond color (use labels, icons, or patterns)
- Text annotations must have sufficient contrast (white on dark, or dark on light)
- Diagrams should use multiple visual cues (color + shape + label) for key information
- Minimum font size of 12pt for all text
- Consider adding alt text suggestions for each image describing the visual content
- Color-blind friendly: Avoid red/green as only differentiator; use orange/blue, patterns, or labels

### Technical Specifications
- **Screenshot Resolution:** Minimum 1920x1080 for full viewport shots, higher for detailed UI panels
- **Image Format:** 
  - PNG for screenshots, renders, composites (lossless)
  - SVG for diagrams, charts, flowcharts, infographics (scalable)
  - JPG acceptable for large composite renders where file size is concern (quality 90+)
- **File Size Target:** 
  - Screenshots/UI: Under 500KB
  - Renders: Under 1MB
  - Composites: Under 2MB
  - SVG: Under 100KB
- **Compression:** Use PNG compression (OptiPNG, TinyPNG) to reduce file size without quality loss
- **Responsive Sizing:** Images should scale well from 800px to 2560px width
