## Production Notes

### Screenshot Capture Workflow
1. **Setup Blender:** Version 4.0+, dark theme, clean workspace
2. **Create scenes:** Template .blend files for each image type
3. **Capture:** 1920x1080 window, multiple takes
4. **Annotate:** Photoshop/GIMP with layer-based annotations
5. **Optimize:** TinyPNG or ImageOptim for compression
6. **Organize:** Follow naming convention exactly

### SVG Diagram Creation
1. **Design:** Figma, Illustrator, or Inkscape
2. **Style guide:** Follow color palette and typography standards
3. **Export:** Optimized SVG, minified
4. **Test:** Verify scalability at various sizes
