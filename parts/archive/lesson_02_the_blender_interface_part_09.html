🎯 Project: Navigate and Customize

Now it's time to put your interface knowledge into practice. This hands-on project will help you become comfortable navigating Blender's interface and making it your own.

Project Overview

You'll complete a series of exercises that cover all the key interface elements we've discussed. Take your time with each step, and don't worry about perfection—this is about building familiarity and muscle memory.

💡 Project Goal

By the end of this project, you'll be able to confidently navigate Blender's interface, switch between workspaces, change editor types, and customize your layout. These foundational skills will serve you throughout your entire Blender journey.

Part 1: Workspace Exploration

Exercise 1: Tour All Workspaces

  1. Open Blender with a new file (File → New → General)
  2. Click through each workspace tab at the top: Layout, Modeling, Sculpting, UV Editing, Texture Paint, Shading, Animation, Rendering, Compositing, Geometry Nodes
  3. For each workspace, spend 30 seconds observing the layout
  4. Notice which editors are visible in each workspace
  5. Return to the Layout workspace

What you're learning: Familiarization with different workspace layouts and their purposes.

Exercise 2: Practice Workspace Switching

  1. Start in Layout workspace
  2. Switch to Modeling workspace
  3. Switch to Shading workspace
  4. Switch back to Layout workspace
  5. Try using Ctrl + Page Up and Ctrl + Page Down to cycle through workspaces
  6. Find which method feels more natural to you

What you're learning: Quick workspace navigation for efficient workflow.

Part 2: Editor Type Mastery

Exercise 3: Change Editor Types

  1. In Layout workspace, find your Timeline at the bottom
  2. Click the editor type icon (top-left of Timeline)
  3. Change it to "Shader Editor"
  4. Change it to "Outliner"
  5. Change it to "Properties"
  6. Change it back to "Timeline"
  7. Observe how the content completely changes with each editor type

What you're learning: Any area can display any editor—total flexibility.

Exercise 4: Split and Join Areas

  1. Hover your mouse over the top-right corner of the 3D Viewport
  2. When cursor changes to crosshair, click and drag down to create a horizontal split
  3. You now have two viewports!
  4. Change the bottom viewport to "Shader Editor" using the editor type icon
  5. Now practice joining: right-click on the border between your two viewports
  6. Select "Join Areas"
  7. Move mouse toward the area you want to keep and click
  8. Your layout is back to normal

What you're learning: Creating custom layouts by splitting and joining areas.

Exercise 5: Resize Areas

  1. Place your cursor on the border between the 3D Viewport and the Outliner
  2. When cursor changes to a double arrow, click and drag
  3. Make the Outliner larger
  4. Make it smaller again
  5. Try resizing other borders in your interface
  6. Find a comfortable size for each area

What you're learning: Adjusting area sizes for better visibility and workflow.

Part 3: Viewport Proficiency

Exercise 6: Shading Mode Practice

  1. Ensure you're in the Layout workspace with the default cube visible
  2. Click the first shading mode circle (Wireframe) - observe the cube
  3. Click the second circle (Solid) - observe the change
  4. Click the third circle (Material Preview) - see the lighting preview
  5. Click the fourth circle (Rendered) - see the full render preview
  6. Now press Z to bring up the shading pie menu
  7. Move your mouse to select different shading modes
  8. Practice switching between modes using both methods

What you're learning: Different viewport display modes for different tasks.

Exercise 7: Toggle Panels

  1. Press T to hide the Toolbar on the left
  2. Press T again to show it
  3. Press N to show/hide the Sidebar on the right
  4. Toggle both panels a few times
  5. Leave them both visible for now

What you're learning: Creating more viewport space when needed.

Part 4: Outliner Operations

Exercise 8: Use the Outliner

  1. Find the Outliner (usually top-right area)
  2. Click on "Cube" in the Outliner—observe it becomes selected in viewport
  3. Click the eye icon next to "Cube"—it disappears from viewport
  4. Click the eye icon again—it reappears
  5. Click on "Light" in the Outliner—it becomes selected
  6. Click on "Camera" in the Outliner—it becomes selected
  7. Try clicking the eye icons for Light and Camera
  8. Make everything visible again

What you're learning: Using the Outliner for selection and visibility control.

Part 5: Properties Panel Navigation

Exercise 9: Explore Properties

  1. Ensure the Cube is selected (click it in viewport or Outliner)
  2. Find the Properties panel (right side, usually)
  3. Click the orange cube icon (Object Properties)
  4. Find the Transform section—you'll see Location, Rotation, Scale values
  5. Click the wrench icon (Modifier Properties)
  6. Click the sphere icon (Material Properties)
  7. Click through a few other property tabs to see what's available
  8. Don't worry about understanding everything—just get familiar with the layout

What you're learning: Where to find different types of properties and settings.

Part 6: Create a Custom Workspace

Exercise 10: Build Your Own Workspace

  1. Start from the Layout workspace
  2. Split the 3D Viewport horizontally so you have two viewport areas
  3. Change the bottom area to "Shader Editor"
  4. Make the Shader Editor take up about 1/3 of the vertical space
  5. Click the + button next to the workspace tabs
  6. Name your workspace "My Custom Workspace"
  7. Your custom workspace now appears in the tabs!
  8. Click between different workspaces and back to yours
  9. Notice your custom layout is preserved

What you're learning: Creating personalized workspace layouts.

Part 7: Preferences Setup

Exercise 11: Configure Auto-Save

  1. Go to Edit → Preferences (or Blender → Preferences on Mac)
  2. Click on "Save & Load" in the left sidebar
  3. Find the "Auto Save" section
  4. Ensure "Auto Save" is checked (enabled)
  5. Set "Timer (mins)" to 3 or 5 minutes
  6. This will automatically save backup copies of your work
  7. Close the Preferences window

What you're learning: Setting up important safety features.

Exercise 12: Try a Different Theme (Optional)

  1. Go to Edit → Preferences → Themes
  2. Click the "Presets" dropdown at the top
  3. Try "Blender Light" or other available themes
  4. See which you prefer—darker themes or lighter ones
  5. Choose the one most comfortable for your eyes
  6. Close Preferences—your choice is automatically saved

What you're learning: Personalizing Blender's appearance for comfort.

Common Questions at This Stage

❓ "There are so many buttons and options—do I need to know them all?"

Absolutely not! Professional Blender artists use maybe 20-30% of the available features regularly. You'll naturally discover and learn features as you need them for specific projects. Focus on understanding the basic interface organization rather than memorizing every button.

❓ "Should I create custom workspaces right away?"

Use the default workspaces first to understand why they're organized the way they are. After you've worked on a few projects and developed preferences, then start creating custom workspaces. Early customization often solves imaginary problems rather than real workflow issues.

❓ "I keep accidentally changing things—is there an undo?"

Yes! Ctrl + Z (or Cmd + Z on Mac) undoes actions in the viewport. For interface changes, you can reload your startup file or switch workspaces to reset layouts. Nothing you do to the interface is permanent—experiment freely!

❓ "Why does Blender use so many keyboard shortcuts?"

Blender's shortcut system was designed by professional animators and VFX artists who needed speed. While you can use menus for everything, shortcuts dramatically accelerate workflow. Learn them gradually—start with the most common ones and add more as you go.
