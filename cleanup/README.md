# cleanup/

Holding area for files that are no longer needed by the project but are kept around in case they're useful for historical reference. Files here are candidates for permanent deletion once their absence is confirmed harmless. Nothing in this folder is referenced by any active doc, HTML, or build process.

## Convention

When a file becomes redundant at the close of a lesson or phase, move it here rather than deleting it. After a few weeks of confirming the file isn't missed, batch-delete from here.
