### Style Consistency Guidelines

**Color Palette (Blender UI Theme):**
- Background: Dark grey (#2b2b2b) - matches Blender's interface
- Selection highlight: Bright orange (#ff8c00) - Blender's active selection color
- Keyframes: Yellow diamonds (#ffd700) - Blender's keyframe color
- Playhead: Bright blue (#2196F3) - Blender's current frame indicator
- Warning/caution: Red (#f44336) - for errors and auto-keyframe active state
- Success/confirmation: Green (#4CAF50) - for correct methods and confirmations
- Text labels: White (#ffffff) for maximum readability on dark backgrounds
- Grid lines: Subtle grey (#404040) - matches Blender's grid appearance
- Properties (keyframed): Orange background (#ff8c00) at low opacity
- Properties (not keyframed): Grey background (#3a3a3a)

**Blender Version:** Blender 4.0+ interface elements for consistency

**Typography:**
- Headers: Bold, sans-serif (e.g., Roboto Bold, Open Sans Bold)
- Body text: Regular sans-serif (e.g., Roboto Regular, Open Sans Regular)
- Code/shortcuts: Monospace font (e.g., Courier New, Monaco)
- Minimum font size: 14pt for readability in screenshots
- High contrast text: White on dark backgrounds, dark on light backgrounds

**Annotation Style:**
- Arrows: Bright orange (#ff8c00), 3-4px width, rounded tips
- Callout boxes: White background with subtle shadow, dark text
- Leaders: Dotted lines from callout to target
- Circles/highlights: Orange outline, 2-3px thickness
- Numbers in sequence: White numbers on orange circles

**Screenshot Standards:**
- Resolution: Minimum 1920x1080 for full interface shots
- Viewport rendering: Solid shading mode (default grey)
- Grid visibility: Enabled where it aids understanding
- Object selection: Orange outline visible on selected objects
- Clean workspace: No distracting elements in background
- Consistent window layouts: Standard arrangements

**Diagram Standards:**
- Clear visual hierarchy: Most important elements largest/brightest
- Consistent iconography: Same icon style throughout all images
- White space: Adequate padding around elements for clarity
- Alignment: Elements aligned to grid for professional appearance
- Scalability: Vector elements (SVG) maintain quality at any size

### Accessibility Considerations

**Visual Accessibility:**
- High contrast ratios: Minimum 4.5:1 for text readability
- Color independence: Don't rely solely on color to convey information
- Clear labels: All elements have text labels, not just color coding
- Icon clarity: Icons recognizable even without color
- Size: Important UI elements clearly visible, not too small

**Alternative Text Recommendations:**
- Timeline images: Describe keyframe locations, playhead position, frame numbers
- Diagram images: Explain relationships, flow direction, key points
- Comparison images: Describe differences between before/after, this vs that
- Interface screenshots: List visible UI elements and their states

**Screen Reader Compatibility:**
- SVG images: Include proper title and desc elements
- Meaningful file names: Descriptive names that explain image content
- Clear image captions: Supplement alt text with visible captions in HTML

### Technical Specifications

**Screenshot Resolution:**
- Full interface shots: 1920x1080 minimum
- Detail shots (menus, panels): 1200x800 minimum
- Composite images: 1600x900 recommended
- Always capture at higher resolution, then scale down for web

**Image Formats:**
- **PNG:** For screenshots, composites, anything with text or UI elements
  - Use PNG-8 for images with limited colors (reduces file size)
  - Use PNG-24 for screenshots with gradients or many colors
  - Optimize with tools like TinyPNG or ImageOptim
- **SVG:** For diagrams, infographics, flowcharts, reference cards
  - Keep file structure clean and well-organized
  - Use text elements (not converted to paths) for editability
  - Include proper viewBox for scaling
- **JPG:** Not recommended for this lesson (no photographic content)

**File Size Targets:**
- Screenshots (PNG): 200-500KB after optimization
- Diagrams (SVG): 50-150KB
- Composite images: 300-600KB maximum
- Total for all 35 images: Under 15MB for page load performance

**Responsive Sizing:**
- Images should scale well from mobile (320px) to desktop (1920px+)
- SVG images: Perfect scaling at any size
- PNG images: Serve at 2x resolution for retina displays, scale down with CSS
- Consider lazy loading for images below the fold
- Use srcset for responsive images if needed
