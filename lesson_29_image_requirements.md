## Notes

### Style Consistency Guidelines
- **Color Palette:**
  - Background: Dark grey (#2b2b2b) - Blender default dark theme
  - Selection/Active: Bright orange (#ff8c00)
  - Wireframe: Cyan (#00ffff) or white (#ffffff)
  - Success indicators: Green (#4CAF50)
  - Error indicators: Red (#ff4444)
  - Annotations: White text on cyan leader lines
  
- **Blender Version:** All screenshots should use Blender 4.0+ interface for consistency
  
- **View Angles:** 
  - Default: 3/4 perspective showing depth and multiple sides
  - Wireframe: Orthographic when showing topology details
  - Settings panels: Straight-on screenshot, properly framed
  
- **Selection Highlighting:** 
  - Active/selected elements: Bright orange (#ff8c00)
  - Target elements: Green highlight
  - Problem areas: Red highlight
  
- **Typography:**
  - Headers: Bold sans-serif (Arial, Helvetica)
  - Body text: Regular sans-serif
  - Annotations: White text, 14-16pt minimum for legibility
  
- **Annotation Style:**
  - Arrow lines: Cyan (#00ffff), 2-3px thickness
  - Arrow heads: Simple triangular style
  - Callout boxes: Rounded corners, semi-transparent dark background
  - Keep annotations minimal and clear

### Accessibility Considerations
- **High Contrast:** Ensure text is readable against backgrounds (WCAG AA minimum)
- **Text Size:** Minimum 14pt for labels, 16pt for important text
- **Color Independence:** Don't rely solely on color (use icons, labels, patterns)
- **Alt Text:** Provide detailed alt text for all images explaining visual content
- **Wireframe Visibility:** Use thicker lines (2-3px) for wireframe images to ensure visibility
- **Icons with Labels:** Always pair icons with text labels, never icons alone
- **Consistent Patterns:** Use same visual language throughout (e.g., green always means success)

### Technical Specifications
- **Screenshot Resolution:** Minimum 1920x1080 for screenshots, higher for detailed close-ups
- **Image Format:**
  - PNG for screenshots and images with transparency or text
  - SVG for diagrams, flowcharts, and icon-based content
