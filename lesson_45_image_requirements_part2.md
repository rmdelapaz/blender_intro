- Use Blender 3.6 or 4.0 for UI consistency
- Dark theme (default) for all interface screenshots
- Ensure consistent icon design across screenshots

**Typography:**
- Interface screenshots: Default Blender font
- Diagrams and infographics: Sans-serif (Roboto, Open Sans, or Arial)
- Code/paths: Monospace font (Courier New, Consolas)
- Headers: Bold weight
- Body text: Regular weight
- Minimum size: 12pt for legibility

**Annotation Style:**
- Arrows: Solid, bright orange (#ff8c00) with 3-4px width
- Highlight boxes: Semi-transparent orange overlay or bright outline
- Labels: White text on semi-transparent dark background for readability
- Callout style: Consistent across all images

**View Angles for 3D Screenshots:**
- Default: 45-degree isometric view unless specific angle needed
- Camera: Positioned to show relevant details clearly
- Lighting: Even, neutral lighting for clarity

**Screenshot Standards:**
- Clean viewport: No unnecessary overlays or clutter
- Object selection: Orange highlight for selected objects
- Resolution: Minimum 1920×1080 for screenshots
- Crop: Focus on relevant area, remove unnecessary space

### **Accessibility Considerations**

**Color Blindness:**
- Don't rely solely on color to convey information
- Use icons, patterns, or labels in addition to color coding
