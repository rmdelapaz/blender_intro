## Notes

### Style Consistency Guidelines
- **Color Palette:** Maintain dark grey background (#2b2b2b), bright orange selection (#ff8c00), cyan/white wireframes, color-coded axes (red X, green Y, blue Z)
- **Blender Version:** All screenshots should use Blender 4.0+ dark theme for consistency
- **View Angles:** Use 3/4 perspective view for depth unless specific view required (side view for profiles, top view for patterns)
- **Selection Highlighting:** Always use bright orange (#ff8c00) for selected elements matching Blender's default
- **Typography:** Clean sans-serif fonts (Arial, Helvetica, Open Sans) for annotations and labels
- **Annotation Style:** Simple bold arrows, avoid decorative elements, high visibility callouts
- **Interface Consistency:** Use default Blender dark theme, standard viewport shading, consistent UI state

### Accessibility Considerations
- **Color Blindness:** Use icons or patterns in addition to color for important distinctions (selected/unselected)
- **Alt Text Required:** Every image needs descriptive alt text for screen readers describing what's shown and why it matters
- **High Contrast:** Maintain sufficient contrast between UI elements, text, and backgrounds
- **Text Size:** Keep annotation text large enough to read when scaled (minimum 14pt equivalent)
- **Clear Visuals:** Avoid cluttered screenshots, focus on one concept per image

### Technical Specifications
- **Screenshot Resolution:** Minimum 1920x1080 source for UI screenshots, crop as appropriate
- **Image Format:** 
  - PNG for screenshots and interface captures (lossless)
  - SVG for diagrams and reference charts (scalable)
  - Avoid JPG except for photorealistic renders
- **File Size Target:** Keep individual images under 500KB for web performance
- **Compression:** Use PNG optimization (TinyPNG, OptiPNG) without quality loss
- **Responsive Design:** Images should work at various viewport sizes (test mobile to desktop)

### Special Considerations for This Lesson
- **Operation Sequences:** Many operations shown as multi-step progressions (3-4 panels)
- **Before/After Comparisons:** Numerous comparison images showing operation effects
- **UI Documentation:** Multiple screenshots showing menu locations and settings panels
- **Live Operations:** Some images show tools active/in-progress (knife cutting, bevel adjusting)
- **Wireframe Visibility:** Many operations best shown in wireframe or mixed mode
- **Selection States:** Critical to show selected vs unselected elements clearly in every image
- **Interactive Feedback:** Some images should show on-screen guides (influence circles, constraint indicators)

### Production Notes
- **Blender Scene Setup:** Create clean master .blend file with common objects for consistent screenshots
- **Lighting Setup:** Use default viewport lighting (no special studio setups needed)
- **Camera Presets:** Save camera positions for standard 3/4 view, side view, top view
- **Sequential Captures:** Take progression images in single session for consistency
- **Annotation Templates:** Create reusable arrow/callout styles for consistent annotations
- **Version Control:** Keep source .blend files and layered annotation files (PSD/XCF) for updates

### Workflow Optimization
- **Batch Similar Images:** Group selection mode examples, take all in one session
- **Reusable Elements:** Some objects (cubes, spheres) used across multiple images
- **Progressive Complexity:** Start with simple examples, save incrementally for progression images
- **UI State Consistency:** Maintain consistent panel visibility, mode states across related images
