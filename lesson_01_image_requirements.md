## Notes

### Style Consistency Guidelines
- Use Blender's signature orange (#FF6B00 or similar) as accent color throughout
- Maintain dark backgrounds where appropriate to match Blender's interface
- Use consistent iconography style (flat, minimal, modern)
- Ensure text is large and readable when images are displayed at web sizes (600-900px wide)
- Keep diagrams clean and uncluttered - prioritize clarity over detail

### Accessibility Considerations
- All diagrams should have high contrast text
- Use color-blind friendly palettes where color coding is used
- Provide text alternatives/descriptions for screen readers
- Ensure SVG text is readable even at different zoom levels
- Consider creating alternate versions for different learning styles (visual, text-heavy, etc.)

### Technical Specifications
- Screenshots: PNG format, 1920x1080 or higher resolution
- Diagrams: SVG preferred for scalability, fallback PNG at 2x resolution
- Infographics: High-quality PNG or SVG, optimized for web
- Maximum file size: 500KB per image (compress appropriately)
- Color space: sRGB for web display consistency

### Content Guidelines
- Avoid showing specific Blender versions that will date quickly (use "4.x" instead of "4.0")
- Keep interface screenshots clean - close unnecessary panels
- Use generic example content rather than copyrighted material
- Maintain professional, educational tone in all visuals
- Consider internationalization - minimize text in raster images
