## Notes

### Style Consistency Guidelines
- **Dark theme mandatory** - All screenshots must use Blender's default dark theme
- **High resolution** - Minimum 1920x1080 for full interface shots
- **Clean annotations** - Use orange/blue for callouts matching Blender's selection colors
- **Consistent object** - Use default cube as reference in viewport shots
- **Professional quality** - No watermarks, clean backgrounds, crisp text

### Accessibility Considerations
- Annotations must have high contrast text
- Use color-blind friendly colors for grouped elements
- Icons should be large enough to identify
- Text labels should be readable at 800px width
- Consider alternative text descriptions for screen readers

### Technical Specifications
- **Screenshots**: PNG format, 1920x1080 or higher
- **Diagrams**: SVG preferred, fallback PNG at 2x resolution
- **Annotations**: Use semi-transparent backgrounds for text boxes
- **Maximum file size**: 800KB per image
- **Color space**: sRGB for web consistency

### Special Considerations for Lesson 02
- **Interface-heavy lesson** - More screenshots than diagrams
- **Reference material** - Many images serve as ongoing references
- **Clear labeling crucial** - Students need to find UI elements quickly
- **Version-specific** - Use Blender 4.0+ interface consistently
- **Annotate heavily** - Don't assume students can identify unlabeled elements
