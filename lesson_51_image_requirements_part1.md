They serve as reference materials that users might zoom into for detail, making SVG's scalability essential.

## Notes

### Style Consistency Guidelines
- **Color Palette:** 
  - Background: Dark grey (#2b2b2b)
  - Primary accent: Bright orange (#ff8c00)
  - Success/completion: Green (#4CAF50)
  - Info/technical: Blue (#2196F3)
  - Creative/artistic: Purple (#9C27B0)
  - Warning/attention: Amber (#FFC107)
  - Text: White (#ffffff) on dark backgrounds
  - Wireframes: Cyan (#00f2fe) or white
- **Blender Version:** Blender 4.0 for UI consistency
- **View Angles:** Camera/viewport angles that clearly show subject
- **Selection Highlighting:** Bright orange (#ff8c00) for selected elements
- **Typography:** 
  - Clean sans-serif for labels and diagrams
  - High contrast for readability
  - Minimum 14pt for small text, 18pt+ for headers
- **Annotation Style:** 
  - Bright orange arrows with white text callouts
  - Subtle dark background boxes behind text for readability
  - Numbered callouts when showing sequence
- **Wireframe Clarity:** Clean edge visibility, avoid cluttered high-density wireframes

### Accessibility Considerations
- **Color Blindness:** Use distinct visual markers beyond color (icons, patterns, text labels)
- **Alt Text Required:** Each image needs descriptive alt text explaining its educational purpose
- **High Contrast:** Maintain 4.5:1 minimum contrast ratio for text
- **Text Size:** Minimum 14pt for body text in diagrams, larger for headers
- **Diagram Simplicity:** Avoid overly complex diagrams; break into multiple simpler images if needed

### Technical Specifications
- **Screenshot Resolution:** Minimum 1920×1080 for quality
- **Image Format:** 
  - PNG for screenshots, composites, and images requiring transparency
  - SVG for diagrams, flowcharts, and technical illustrations
  - JPG for large photographic-style renders (with 85-95% quality)
- **File Size Target:** 
  - PNG: Under 2MB per image (optimize with compression)
  - SVG: Naturally small, typically under 100KB
  - JPG: Under 500KB for web use
- **Compression:** Use lossless compression for PNGs, smart compression for JPGs
- **Responsive Sizing:** Images should work at various sizes; test readability at 50% scale

### Special Considerations for This Lesson
- **Portfolio focus:** Images should exemplify portfolio-quality work, not just demonstrate concepts
- **Motivation factor:** Many images should inspire and excite students about their own projects
- **Diverse examples:** Show variety of styles, subjects, and approaches to accommodate different student interests
- **Process visualization:** Emphasize showing workflow progressions, not just final results
- **Practical guidance:** Images should provide actionable reference material students can use during production
- **Professional standards:** All example work should meet or exceed portfolio quality standards

### Production Notes
- **Blender Scene Setup:** 
  - Use clean, professional lighting setups for all 3D examples
  - Ensure topology examples use proper quad-based modeling
  - Material examples should show realistic PBR properties
- **Lighting Setup:** 
  - Consistent studio lighting or HDRI across product shots
  - Clear directional lighting for diagram clarity
  - Atmospheric lighting for environment examples
- **Camera Angles:** 
  - ¾ view for most objects and characters
  - Eye-level for environment scenes
  - Top-down or orthographic for technical diagrams
- **Batch Processing:** 
  - Create base scenes that can be adapted for multiple examples
  - Reuse lighting setups across similar image types
  - Template compositions for consistent styling
- **Version Control:** 
  - Keep source .blend files for all 3D examples
  - Save SVG source files with editable text/shapes
  - Maintain layer files for composites
- **Template Reuse:**

  - Develop standard diagram templates
