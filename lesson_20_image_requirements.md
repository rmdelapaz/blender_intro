## Notes

### Style Consistency Guidelines
- **Color Palette Standards:**
  - Background: Dark grey (#2b2b2b) - matches Blender's default dark theme
  - Selection highlight: Bright orange (#ff8c00) - Blender's selection color
  - Wireframe/Grid: Cyan (#00ffff) or white (#ffffff) for high visibility
  - Annotations/Labels: White text (#ffffff) with subtle drop shadow for readability
  - Warning/Error: Red (#ff0000)
  - Success/Good example: Green (#4CAF50)
  - Active elements: Bright orange (#ff8c00)
  - Guide overlays: Semi-transparent cyan or yellow
  
- **Blender Version:** Use Blender 4.0 or later interface for consistency with course
- **View Angles:** Use 3/4 perspective views for 3D objects to show depth and structure
- **Selection Highlighting:** Use orange outline for selected objects (Blender standard)
- **Typography:** 
  - Labels: Sans-serif font (Arial, Helvetica, or Roboto)
  - Body text: 16-18pt minimum for readability
  - Headers: 24-28pt bold
  - Use white text with subtle black stroke/glow for visibility over any background
- **Annotation Style:** 
  - Arrows: Simple solid arrows with round heads
  - Callout lines: Dashed lines connecting labels to elements
  - Emphasis boxes: Rounded rectangles with bright outline
  - Consistent arrow and line thickness (2-3px)

### Accessibility Considerations
- **High Contrast:** All text must have 4.5:1 contrast ratio minimum against backgrounds
- **Color Independence:** Don't rely solely on color to convey information; use labels, icons, patterns
- **Text Size:** Minimum 14pt for body text, 16pt preferred for diagrams
- **Alt Text Requirement:** Each image needs descriptive alt text for screen readers:
  - Describe what's shown in image
  - Explain key concepts image demonstrates
  - Note important labels or callouts
  - Example: "Side-by-side comparison showing viewport navigation on left and camera view with orange frame border on right, demonstrating the critical difference between working view and render view"
- **SVG Text:** Use actual text elements in SVG, not converted paths, for screen reader accessibility

### Technical Specifications
- **Screenshot Resolution:** 1920x1080 minimum for full-screen captures
- **Diagram Resolution:** 1920x1080 standard; 2400x800 for wide panoramic comparisons
- **Interface Screenshots:** 1200x1600 for vertical panels (outliner, properties)
- **Image Formats:** 
  - PNG for screenshots, renders, photographic examples (supports transparency)
  - SVG for diagrams, infographics, charts (scalable, small file size)
  - No JPG due to compression artifacts affecting technical diagrams
- **File Size Targets:** 
  - PNG screenshots: Under 500KB (use PNG optimization)
  - PNG renders: Under 1MB
  - SVG diagrams: Under 100KB
- **Compression:** Use PNG optimization tools (pngcrush, optipng) to reduce file size without quality loss
- **Responsive Sizing:** Images should be responsive in HTML; max-width: 100%; height: auto;

### Special Considerations for This Lesson
This is a camera fundamentals lesson covering extensive ground from basic concepts to advanced constraints. Key considerations:

1. **Focal Length is Critical:** Images #4, #6, #7, #22, #29 all relate to focal length because it's the single most important creative decision in camera work. Multiple visual examples needed to truly understand perspective effects.

2. **Composition Foundation:** Images #9, #10, #12, #13 teach composition because camera position means nothing without good framing. Rule of Thirds must be crystal clear.

3. **Interface Navigation:** Images #3, #14, #17, #18 help students find and use camera tools efficiently. Without these, students waste time hunting for settings.

4. **Comparison is Key:** Many images use side-by-side or multi-panel comparisons (#2, #4, #5, #8, #10, #13, #25, #30) because camera concepts are best understood through direct visual comparison rather than single examples.

5. **Professional Workflow:** Images showing constraints (#15, #16), organization (#17), and advanced features (#19, #20, #21, #26) demonstrate industry-standard techniques that separate beginners from professionals.

6. **Psychological Impact:** Camera angle images (#8, #11) are crucial because they bridge technical knowledge with storytelling - students must understand that camera choices convey emotion and meaning.
