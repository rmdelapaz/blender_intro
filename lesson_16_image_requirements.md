  - Orange arrows (#ff8c00) with white text labels
  - Arrow width: 3-4px for visibility
  - Labels positioned to avoid obscuring critical content
  - Use leader lines when necessary for clarity

### Accessibility Considerations
- **High Contrast:** Ensure text and important elements have 4.5:1 contrast ratio minimum
- **Color Independence:** Never rely solely on color to convey information (use labels, shapes, patterns)
- **Alt Text Requirements:** All images need descriptive alt text explaining:
  - What the image shows
  - Key concepts illustrated
  - Relationships between elements
- **Text Size:** Keep text in infographics large enough to read at 1920x1080 resolution
- **Annotations:** Clear, unambiguous labels that work without color if needed

### Technical Specifications
- **Screenshot Resolution:** 1920x1080 minimum for all Blender interface screenshots
- **Diagram Resolution:** 1920x1080 for standard diagrams, 2400x800 for wide comparisons
- **Image Formats:**
  - PNG for screenshots, renders, composites (lossless, supports transparency)
  - SVG for diagrams, charts, infographics (scalable, crisp at any size, small file size)
  - JPG not recommended (lossy, no transparency, larger than PNG for UI screenshots)
- **File Size Target:**
  - PNG screenshots: Under 500KB each (use compression tools like pngquant)
  - PNG composites: Under 1MB each
  - SVG diagrams: Under 100KB each (text as paths for font embedding)
- **Compression:** Use lossless compression (OptiPNG, pngcrush) to reduce file size without quality loss
- **Responsive Sizing:** Images should scale well from 320px mobile to 2560px desktop
  - Test at 768px, 1024px, 1920px widths
  - Ensure text remains legible at smaller sizes
