**Screenshot Resolution:**
- Minimum: 1920×1080 (Full HD)

- Save at 2x display resolution then scale down for final use (sharper result)

  - Settings: PNG-24 with alpha if transparency needed

  - Use for: Diagrams, charts, infographics, node graphs

  - Avoid unless file size critical

- Individual images: Under 500KB each (aim for 200-300KB)
